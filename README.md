# A Ramcharan Portfolio

A standalone portfolio inspired by the editorial, motion-led feel of vanlent.dev, rebuilt with original copy and A Ramcharan's resume/profile details.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

- Replace `assets/profile.png` with another portrait if desired.
- Update project links in `index.html` when GitHub/demo URLs are available.
- Update the Google Fonts imports in `style.css` if you want self-hosted fonts.
- GSAP is loaded from jsDelivr in `index.html` for scroll-reveal motion.
